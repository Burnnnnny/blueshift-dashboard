# 결론 (Conclusion)

축하합니다! Surfpool 테스트 과정을 완료했습니다. 이제 원활한 교차 프로그램 호출(CPI) 테스트를 위해 메인넷 상태를 로컬 개발 환경으로 직접 가져오는 강력한 테스트 프레임워크인 Surfpool을 사용하는 방법을 포괄적으로 이해하게 되었습니다.

<ArticleSection name="배운 내용" id="what-you-learned" level="h2" />

이 과정 전반에 걸쳐 필수적인 Surfpool 개념을 마스터했습니다:
- **메인넷 시뮬레이션**: Surfpool이 메인넷 계정을 적시에 가져와 CPI 테스트를 위한 복잡한 설정을 제거하는 방법
- **고급 제어**: 모든 에포크/슬롯/타임스탬프로 시간 여행, 블록 생성 일시 중지 및 시스템 변수 조작
- **계정 수정**: SOL 공급 파라미터 설정, 프로그램 간 계정 전송 및 토큰 계정 데이터 업데이트
