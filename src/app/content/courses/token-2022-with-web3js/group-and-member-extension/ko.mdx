# 그룹 및 멤버 확장 (The Group and Member Extension)

`Group` 및 `Member` 확장은 여러 자산과 연결된 NFT 컬렉션과 같은 그룹을 생성할 수 있는 기능을 도입한 `Mint` 계정 확장입니다.

<ArticleSection name="Mint 계정 초기화" id="initializing-the-mint-account" level="h2" />

`Member` 및 `Group` 확장은 `Mint` 계정에 적용되는 2개의 서로 다른 확장으로 구성되어 있기 때문에 우리가 익숙한 것과는 조금 다릅니다:
- 그룹 또는 멤버에 대한 모든 정보가 포함된 `Extension`.
- `Group` 또는 `Member` 확장이 있는 `Mint` 계정을 참조하는 `Pointer Extension`.

일반적으로 사용될 때 `Extension`과 `Pointer Extension`은 동일한 `Mint` 계정에 존재하며 이 예제에서도 동일하게 수행할 것입니다.

> `Group`과 `Member` 확장은 동일한 계정에 있을 수 없습니다.

코드로 들어가기 전에 몇 가지 기본 사항부터 시작하겠습니다:

`GroupPointer` 및 `MemberPointer` 확장은 `@solana/spl-token` 패키지에 있지만 `Group` 및 `Member`를 초기화하려면 `@solana/spl-token-group` 패키지를 사용해야 합니다.

필요한 패키지를 설치해 봅시다:

```
npm i @solana/spl-token-group
```

또한 `Group` 및 `Member` 확장은 `Mint` 계정을 초기화한 후 확장을 초기화해야 하는 "유일한" 확장 중 하나입니다.

이는 메타데이터 초기화 명령어가 그룹 및 멤버 콘텐츠의 길이에 필요한 공간을 동적으로 할당하기 때문입니다.

동시에, 이는 `Group` 또는 `Member` 확장이 포함된 채로 임대 면제될 만큼 충분한 람포트로 `Mint` 계정을 초기화해야 함을 의미하지만, `token_group_initialize()` 및 `token_group_member_initialize()` 명령어가 실제로 공간을 올바르게 늘리기 때문에 `GroupPointer` 또는 `MemberPointer` 확장에만 충분한 공간을 할당합니다.

코드에서 `Group`을 초기화하는 것은 다음과 같습니다:

```ts
const mint = Keypair.generate();

// Size of Mint Account with extensions
const mintLen = getMintLen([ExtensionType.GroupPointer]);

// Minimum lamports required for Mint Account
const lamports = await connection.getMinimumBalanceForRentExemption(mintLen + TYPE_SIZE + LENGTH_SIZE + TOKEN_GROUP_SIZE);

const createAccountInstruction = SystemProgram.createAccount({
    fromPubkey: keypair.publicKey,
    newAccountPubkey: mint.publicKey,
    space: mintLen,
    lamports,
    programId: TOKEN_2022_PROGRAM_ID,
});

const initializeGroupPointer = createInitializeGroupPointerInstruction(
    mint.publicKey,
    keypair.publicKey,
    mint.publicKey,
    TOKEN_2022_PROGRAM_ID,
);

const initializeMintInstruction = createInitializeMintInstruction(
    mint.publicKey,
    6,
    keypair.publicKey,
    null,
    TOKEN_2022_PROGRAM_ID,
);

const initializeGroupInstruction = createInitializeGroupInstruction(
    {
        programId: TOKEN_2022_PROGRAM_ID,
        group: mint.publicKey,
        mint: mint.publicKey,
        mintAuthority: keypair.publicKey,
        updateAuthority: keypair.publicKey,
        maxSize: BigInt(100),
    }
);

const transaction = new Transaction().add(
    createAccountInstruction,
    initializeGroupPointer,
    initializeMintInstruction,
    initializeGroupInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair, mint], {commitment: "finalized"});

console.log(`Mint created! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

그리고 그 후 방금 만든 그룹을 사용하여 다음과 같이 멤버를 추가할 수 있습니다:

```ts
const member = Keypair.generate();

// Size of Member Account with extensions
const memberLen = getMintLen([ExtensionType.GroupMemberPointer]);

// Minimum lamports required for Member Account
const lamports = await connection.getMinimumBalanceForRentExemption(memberLen + TYPE_SIZE + LENGTH_SIZE + TOKEN_GROUP_MEMBER_SIZE);

const createAccountInstruction = SystemProgram.createAccount({
    fromPubkey: keypair.publicKey,
    newAccountPubkey: member.publicKey,
    space: memberLen,
    lamports,
    programId: TOKEN_2022_PROGRAM_ID,
});

const initializeGroupMemberPointer = createInitializeGroupMemberPointerInstruction(
    member.publicKey,
    keypair.publicKey,
    member.publicKey,
    TOKEN_2022_PROGRAM_ID,
);

const initializeMintInstruction = createInitializeMintInstruction(
    member.publicKey,
    6,
    keypair.publicKey,
    null,
    TOKEN_2022_PROGRAM_ID,
);

const initializeGroupMemberInstruction = createInitializeMemberInstruction(
    {
        programId: TOKEN_2022_PROGRAM_ID,
        group: mint.publicKey,
        member: member.publicKey,
        memberMint: member.publicKey,
        memberMintAuthority: keypair.publicKey,
        groupUpdateAuthority: keypair.publicKey,
    }
);

const transaction = new Transaction().add(
    createAccountInstruction,
    initializeGroupMemberPointer,
    initializeMintInstruction,
    initializeGroupMemberInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair, member], {commitment: "finalized"});

console.log(`Member created! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```
