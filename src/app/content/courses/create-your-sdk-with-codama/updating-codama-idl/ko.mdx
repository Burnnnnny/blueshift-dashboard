# Codama IDL 업데이트 (Update your Codama IDL)

Codama의 방문자 시스템을 사용하면 생성 후 IDL을 프로그래밍 방식으로 변환하고 향상시킬 수 있습니다.

Anchor IDL에서 시작했든 처음부터 구축했든, 방문자를 사용하면 클라이언트를 생성하기 전에 Codama IDL을 더욱 풍부하게 만들고 사용자 정의하여 예를 들어 개발자 경험을 최적화할 수 있습니다.

<ArticleSection name="필수 방문자" id="essential-visitors" level="h2" />

방문자는 방문자 패턴을 따라 IDL 노드를 순회하고 변환을 적용합니다.

프로덕션 준비 SDK를 생성하는 데 가장 큰 영향을 미치는 방문자를 살펴보겠습니다:

### PDA 추가 방문자 (Add PDAs Visitors)

프로그램에 PDA 정의를 추가하려면 `addPdasVisitor`를 사용합니다. 이 방문자는 Anchor IDL에 PDA 정보가 포함되어 있지 않지만 프로그램 로직이 특정 프로그램 파생 주소에 의존하는 경우 필수적입니다.

이는 키가 프로그램 이름이고 값이 추가할 PDA 정의 배열인 객체를 받습니다.

```ts
codama.update(
    addPdasVisitor({
        // 'token' 프로그램에 PDA 추가.
        token: [
            {
                name: 'associatedToken',
                seeds: [
                    variablePdaSeedNode('mint', publicKeyTypeNode()),
                    constantPdaSeedNode(
                        publicKeyTypeNode(),
                        publicKeyValueNode('TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA'),
                    ),
                    variablePdaSeedNode('owner', publicKeyTypeNode()),
                ],
            },
        ],
        // 'counter' 프로그램에 두 개의 PDA 추가.
        counter: [
            {
                name: 'counter',
                seeds: [variablePdaSeedNode('authority', publicKeyTypeNode())],
            },
            {
                name: 'counterConfig',
                seeds: [variablePdaSeedNode('counter', publicKeyTypeNode())],
            },
        ],
    }),
);
```

### 계정 업데이트 방문자 (Update Accounts Visitor)

기존 계정 정의를 수정하거나 원하지 않는 계정을 제거하려면 `updateAccountsVisitor`를 사용합니다. 이 방문자는 선호하는 명명 규칙과 일치하도록 계정 이름을 바꾸거나 누락된 PDA 연결을 추가하는 데 중요합니다.

Anchor 생성 계정 이름이 클라이언트 명명 선호도와 일치하지 않거나 더 나은 코드 생성을 위해 PDA를 특정 계정과 연결해야 할 때 이를 사용해야 합니다.

```ts
codama.update(
    updateAccountsVisitor({
        vault: {
            // 'vault' 계정 이름을 'safe'로 변경.
            name: 'safe',
            // 'owner' 필드 이름을 'authority'로 변경.
            data: { owner: 'authority' },
            // 새 PDA 노드를 생성하고 이 계정에 연결.
            seeds: [variablePdaSeedNode('authority', publicKeyTypeNode())],
        },
        counter: {
            // 'counter' 계정 삭제.
            delete: true,
        },
    }),
);
```

### 명령어 업데이트 방문자 (Update Instructions Visitor)

더 나은 기본값, 이름 지정 또는 계정 구성으로 명령어 정의를 향상시키려면 `updateInstructionsVisitor`를 사용합니다. 이것은 생성된 클라이언트의 개발자 경험을 개선하는 가장 강력한 방문자 중 하나입니다.

명령어 인수에 합리적인 기본값을 제공하거나, 명확성을 위해 명령어 또는 계정 이름을 바꾸거나, 클라이언트 사용을 단순화하기 위해 계정을 선택 사항으로 표시하려는 경우 이를 사용해야 합니다.

```ts
codama.update(
    updateInstructionsVisitor({
        send: {
            // 'send' 명령어 이름을 'transfer'로 변경.
            name: 'transfer',
            accounts: {
                // 'owner' 명령어 계정 이름을 'authority'로 변경.
                owner: { name: 'authority' },
                // 'associatedToken' 명령어 계정에 대한 기본값 설정.
                associatedToken: { defaultValue: pdaValueNode('associatedToken') },
                // 'payer' 명령어 계정의 서명자 상태를 `true`로 업데이트.
                payer: { isSigner: true },
                // 'mint' 명령어 계정을 선택 사항으로 표시.
                mint: { isOptional: true },
            },
            arguments: {
                // 'amount' 명령어 인수에 대한 기본값을 1로 설정.
                amount: { defaultValue: numberValueNode(1) },
                // 'decimals' 명령어 인수 이름을 'mintDecimals'로 변경.
                decimals: { name: 'mintDecimals' },
            },
        },
        burn: {
            // 'burn' 명령어 삭제.
            delete: true,
        },
    }),
);
```

### 정의된 타입 업데이트 방문자 (Update Defined Types Visitor)

사용자 정의 타입 정의를 수정하거나 사용하지 않는 타입을 정리하려면 `updateDefinedTypesVisitor`를 사용합니다. 이 방문자는 생성된 클라이언트에서 깔끔하고 잘 명명된 타입을 유지하는 데 도움이 됩니다.

Anchor가 선호하는 규칙과 일치하지 않는 타입 이름을 생성하거나 IDL에서 사용되지 않는 타입을 제거해야 할 때 이를 사용해야 합니다.

```ts
codama.update(
    updateDefinedTypesVisitor({
        options: {
            // 'options' 타입 이름을 'configs'로 변경.
            name: 'configs',
            // 'sol' 필드 이름을 'lamports'로 변경.
            data: { sol: 'lamports' },
        },
        player: {
            // 'player' 타입 삭제.
            delete: true,
        },
    }),
);
```

### 오류 업데이트 방문자 (Update Errors Visitor)

더 명확한 이름, 메시지 또는 코드로 오류 정의를 개선하려면 `updateErrorsVisitor`를 사용합니다. 이 방문자는 오류 처리가 설명적이고 일관된 패턴을 따르도록 보장합니다.

Anchor가 생성하는 것보다 더 설명적인 오류 이름이나 메시지를 원하거나 프로그램 제품군 전체에서 오류 코드를 표준화해야 할 때 이를 사용해야 합니다.

```ts
codama.update(
    updateErrorsVisitor({
        invalidPda: {
            // 'invalidPda' 오류 이름을 'invalidProgramDerivedAddress'로 변경.
            name: 'invalidProgramDerivedAddress',
            // 오류 메시지 변경.
            message: 'The program-derived address is invalid.',
            // 오류 코드 변경.
            code: 123,
        },
        accountMismatch: {
            // 'accountMismatch' 오류 삭제.
            delete: true,
        },
    }),
);
```

### 프로그램 업데이트 방문자 (Update Programs Visitor)

이름, 버전 또는 공개 키와 같은 프로그램 수준 정보를 수정하려면 `updateProgramsVisitor`를 사용합니다. 이 방문자는 정확한 프로그램 메타데이터를 유지 관리하는 데 필수적입니다.

프로그램 버전을 업데이트하거나, 환경 전반에 걸쳐 프로그램 이름을 표준화하거나, IDL에서 사용되지 않는 프로그램을 제거해야 할 때 이를 사용해야 합니다.

```ts
codama.update(
    updateProgramsVisitor({
        splToken: {
            // 'splToken' 프로그램 이름을 'token'으로 변경.
            name: 'token',
            // 프로그램 버전 변경.
            version: '3.0.0',
            // 프로그램의 공개 키 변경.
            publicKey: 'TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA',
        },
        splAssociatedToken: {
            // 'splAssociatedToken' 프로그램 삭제.
            delete: true,
        },
    }),
);
```
