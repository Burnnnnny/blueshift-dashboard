# 메타플렉스 토큰 메타데이터 프로그램 (Metaplex Token Metadata Program)

Solana에서 토큰을 출시했는데 모든 지갑에서 "7xKXtg2CW87d97TXJSDpbD5jBkheTqA83TZRuJosgAsU"와 같은 의미 없는 문자열로 나타난다고 상상해 보세요.

사용자는 자신이 무엇을 가지고 있는지 전혀 알 수 없으며 신중하게 만든 프로젝트는 네트워크에 넘쳐나는 다른 수천 개의 익명 토큰과 구별할 수 없습니다.

Metaplex Token Metadata 프로그램은 익명의 블록체인 항목을 브랜드화되고 인식 가능한 디지털 자산으로 변환하여 이 중요한 문제를 해결합니다.

SPL-Token 프로그램은 소유권 추적, 공급 관리 및 전송 촉진과 같은 기술적 메커니즘에서 탁월하지만 토큰을 사람이 읽을 수 있는 컨텍스트가 없는 뼈대만 있는 데이터 구조로 남겨둡니다.

이곳이 Metaplex가 원시 블록체인 기능과 사용자 경험 간의 격차를 해소하는 마법을 발휘하는 곳입니다. 암호화된 주소 대신 사용자는 익숙한 로고, 명확한 설명 및 토큰을 실제 세계에서 실제로 사용할 수 있게 만드는 모든 상황 정보와 함께 "Solana (SOL)"를 보게 됩니다.

<ArticleSection name="메타데이터 계정" id="metadata-account" level="h2" />

`Metadata` 계정은 단순한 민트 주소를 인식 가능한 자산으로 변환하는 모든 정보를 저장하여 토큰의 디지털 신분증 역할을 합니다.

이것은 단순히 예쁜 이름과 사진에 관한 것이 아닙니다. 전체 Solana 생태계에서 토큰이 표시되는 방식에 대한 기반을 만드는 것입니다.

Solana의 프로그램 파생 주소 시스템을 사용하여 모든 토큰은 민트에 수학적으로 연결된 정확히 하나의 메타데이터 계정을 얻습니다. 이는 기술 토큰과 설명 정보 사이에 끊을 수 없는 유대를 형성하여 모든 애플리케이션에서 일관성을 보장하고 ID 충돌을 방지합니다:

```rust
const ID: Pubkey = solana_pubkey::pubkey!("metaqbxxUerdq28cj1RbAWkYQm3ybzjb6a8bt518x1s");

const PREFIX: &str = "metadata";

let (metadata, _) = Pubkey::find_program_address(
    &[
        PREFIX.as_bytes(), 
        &ID, 
        mint.as_ref()
    ], 
    &ID  
);
```

메타데이터 계정은 애플리케이션이 자산을 올바르게 표시하는 데 필요한 모든 것을 포함하는 토큰의 범용 여권이 됩니다.

토큰 이름은 이해할 수 없는 주소를 대체하고 기호는 즉각적인 인식(위의 긴 문자열 대신 "SOL" 생각)을 제공하며 URI 참조는 로고 및 자세한 설명과 같은 리치 미디어를 가리킵니다.

그 결과는? 토큰은 블록체인에만 존재하는 것이 아니라 지갑에서 번성하고 탐색기에서 전문적으로 나타나며 Solana 생태계 전반의 애플리케이션과 원활하게 통합됩니다.

> `Token Metadata` 프로그램을 사용하는 방법에 대해 자세히 알아보려면 [공식 문서](https://developers.metaplex.com/token-metadata)를 참조하세요.
