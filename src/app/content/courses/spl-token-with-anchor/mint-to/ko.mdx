# Mint To 명령어 (Mint To Instruction)

새로운 토큰을 생성하고 지정된 계정에 입금합니다. 오직 민트 권한(mint authority)만이 이 작업을 수행할 수 있습니다.

토큰을 발행(mint)하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- `mintAuthority`를 보유하고 있는 초기화된 `Mint` 계정
- 토큰을 발행할 초기화된 `Token` 계정 또는 `Associated Token` 계정

> 우리가 발행하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 발행하려면 실제로는 수량으로 `1_000_000`을 입력해야 합니다.

`mint_to()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
mint_to(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        MintTo {
            mint: ctx.accounts.mint_account.to_account_info(),
            to: ctx.accounts.to_token_account.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &1_000_000,
)?;
```
