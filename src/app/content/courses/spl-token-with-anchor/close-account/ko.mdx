# 계정 닫기 명령어 (Close Account Instruction)

토큰 계정을 닫고 남은 SOL 임대료를 대상 계정으로 전송합니다. 네이티브 SOL 계정이 아닌 한 토큰 계정의 잔액은 0이어야 합니다.

> Token2022부터는 공급량이 0인 `Mint` 계정을 닫는 것이 가능합니다.

토큰 계정을 닫기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정
- 내부에 토큰이 없는 초기화된 `Token` 계정 또는 `Associated Token` 계정

`close_account()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
close_account(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        CloseAccount {
            account: ctx.accounts.token_account.to_account_info(),
            destination: ctx.accounts.authority.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
)?;
```
