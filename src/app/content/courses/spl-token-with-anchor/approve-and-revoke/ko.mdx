# 승인 및 철회 명령어 (Approve and Revoke Instructions)

승인(Approve)은 위임자(delegate)에게 계정 소유자를 대신하여 특정 수량의 토큰을 전송할 수 있는 권한을 부여합니다. 이를 통해 전체 계정 제어권을 주지 않고도 프로그래밍 방식의 토큰 전송이 가능해집니다.

> "승인된" 수량을 설정하며, 위임자는 그 수량까지만 전송할 수 있습니다.

철회(Revoke)는 계정에 대한 현재 위임자의 권한을 제거하여, 계정 소유자에게 전체 제어권을 반환합니다.

> 기존 위임을 즉시 취소하며, 오직 계정 소유자만이 위임을 철회할 수 있습니다(위임자 자체는 불가능).

토큰 계정을 위임하거나 철회하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정.
- 제어권을 가져올 초기화된 `Token` 계정 또는 `Associated Token` 계정

> 우리가 발행하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 발행하려면 실제로는 수량으로 `1_000_000`을 입력해야 합니다.

`approve()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
approve(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Approve {
            to: ctx.accounts.token_account.to_account_info(),
            delegate: ctx.accounts.delegate.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &1_000_000,
)?;
```

그리고 `revoke()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
revoke(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Revoke {
            pub source: ctx.accounts.token_account.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
)?;
```
