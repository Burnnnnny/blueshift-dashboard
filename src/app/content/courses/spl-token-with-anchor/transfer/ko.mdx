# 전송 명령어 (Transfer Instruction)

한 계정에서 다른 계정으로 토큰을 이동합니다. 이것은 사용자 간에 토큰을 보내는 기본 작업입니다.

토큰을 전송하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정.
- 전송하려는 수량 이상을 이미 보유하고 있는 소스 `Token` 계정 또는 `Associated Token` 계정.
- 소스 `Token` 계정으로부터 토큰을 받을 대상 `Token` 계정 또는 `Associated Token` 계정.

> 우리가 전송하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 전송하려면 실제로는 수량으로 `1_000_000`을 입력해야 합니다.

`transfer()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
transfer(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Transfer {
            from: ctx.accounts.from_token_account.to_account_info(),
            to: ctx.accounts.to_token_account.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &1_000_000,
)?;
```
