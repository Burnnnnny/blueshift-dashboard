# 권한 설정 명령어 (Set Authority Instructions)

민트나 계정의 권한을 변경합니다. 이를 통해 소유권을 이전하거나 특정 권한 유형을 업데이트할 수 있습니다.

토큰이나 토큰 계정에 대한 권한을 설정하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- `mintAuthority`나 `freezeAuthority`를 보유하고 있는 초기화된 `Mint` 계정
- 우리가 소유한 초기화된 `Token` 계정 또는 `Associated Token` 계정

`set_authority()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
set_authority(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        SetAuthority {
            account_or_mint: ctx.accounts.mint_account.to_account_info(),
            to: ctx.accounts.to_token_account.to_account_info(),
            current_authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &spl_token::instruction::AuthorityType::MintTokens, // authority_type
    Some(new_authority.key()) // new_autority
)?;
```
