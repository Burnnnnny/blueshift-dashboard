# 소각 명령어 (Burn Instruction)

유통에서 제거하여 토큰을 영구적으로 파괴합니다. 이는 토큰의 총 공급량을 줄입니다.

토큰을 소각하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정.
- 소각하려는 수량 이상을 이미 보유하고 있는 `Token` 계정 또는 `Associated Token` 계정.

> 우리가 소각하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 소각하려면 실제로는 수량으로 `1_000_000`을 입력해야 합니다.

`burn()` 명령어에 대한 CPI는 다음과 같습니다:

```rust
burn(
    CpiContext::new(
        ctx.accounts.token_program.to_account_info(),
        Burn {
            mint: ctx.accounts.mint.to_account_info(),
            from: ctx.accounts.token_account.to_account_info(),
            authority: ctx.accounts.authority.to_account_info(),
        },
    ),
    &1_000_000,
)?;
```
