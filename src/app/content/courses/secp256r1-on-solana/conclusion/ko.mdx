# 결론 (Conclusion)

축하합니다! Solana에서의 Secp256r1 과정을 완료했습니다. 이제 Solana에서 Secp256r1이 어떻게 작동하는지와 최신 인증 방법을 활성화하는 역할에 대해 확실히 이해하게 되었습니다.

<ArticleSection name="배운 내용" id="what-you-learned" level="h2" />

이 과정 전반에 걸쳐 다음에 대한 필수 지식을 얻었습니다:
- Secp256r1 (NIST P-256) 타원 곡선 암호화의 기초
- Solana가 프리컴파일을 통해 Secp256r1 서명 검증을 구현하는 방법
- Secp256r1과 패스키와 같은 최신 인증 방법 간의 관계
- 프로그램에서 보안 서명 검증을 구현하는 방법
- Secp256r1 공개 키와 함께 PDA를 사용하는 모범 사례

<ArticleSection name="다음 단계" id="next-steps" level="h2" />

이제 Solana에서 Secp256r1을 사용하여 보안 인증 시스템을 구축할 준비가 되었습니다! 다음은 권장되는 다음 단계입니다:

1. 자신의 프로그램에서 Secp256r1 서명 검증 구현 실험
2. 실습 연습을 위해 [도전 과제 섹션](/ko/challenges) 탐색
3. Secp256r1을 사용하여 애플리케이션 보안을 개선할 수 있는 방법 고려
4. 커뮤니티에 참여하여 구현 공유 및 도움 받기

Secp256r1이 암호화 기반을 제공하지만 보안 인증을 구현하려면 다음 사항을 신중하게 고려해야 함을 기억하십시오:
- 적절한 서명 검증
- 보안 키 관리
- 재생 공격(Replay attacks)으로부터 보호
- 사용자 경험 고려 사항

실험하고 실수하는 것을 두려워하지 마십시오. 그것이 우리가 암호학 및 보안 분야에서 배우고 성장하는 방식입니다!
