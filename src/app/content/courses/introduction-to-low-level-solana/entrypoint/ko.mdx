# 진입점 (The Entrypoint)

`entrypoint!()`는 모든 Solana 프로그램이 노출해야 하는 단일 심볼입니다. 이는 Solana 런타임이 로더에서 코드로 점프하는 핸드오프 지점입니다.

점프하기 전에 로더는 명령어가 필요한 모든 것을 BPF VM의 입력 페이지에 저장된 하나의 평면 C 스타일 레코드로 팩킹합니다. 그런 다음 매크로는 해당 레코드의 압축을 풀고 Rust에 세 가지 안전 슬라이스와 참조를 전달합니다:
- **program_id**: 현재 실행 중인 프로그램의 pubkey.
- **accounts**: AccountInfo 레코드의 연속 배열에 대한 포인터와 길이.
- **instruction_data**: 트랜잭션에서 제공한 원시 바이트의 포인터 더하기 길이 슬라이스.

매크로는 다음을 수행합니다:
- 해당 원시 포인터를 안전한 Rust 슬라이스로 변환.
- VM을 충돌시키는 대신 깨끗한 `ProgramError::Custom` 코드가 되도록 패닉을 잡습니다.
- `ProgramResult`를 반환하는 사용자 정의 함수(종종 `process_instruction`이라고 함)로 모든 것을 전달합니다.

다음은 Solana 로더가 진입점으로 점프하기 전에 BPF VM의 입력 페이지에 배치하는 단일 평면 레코드에 대한 설명입니다.

```rust
pub struct Entrypoint {
    account_len: u64,
    account_info: [AccountRaw; account_len]
    instruction_len: u64,
    instruction_data: [u8; instruction_len]
    program_id: [u8; 32],
}
```
- `account_len`: 전송된 계정 수.
- `account_info`: 명령어에 있는 원시 계정 레코드, 차례대로.
- `instruction_len`: 뒤따르는 명령어 데이터의 바이트 수.
- `instruction_data`: 명령어 자체.
- `program_id`: 실행 중인 프로그램의 32바이트 `Pubkey`.

`account_info` 배열의 모든 요소는 동일한 압축 레이아웃을 따릅니다:

```rust
pub struct AccountRaw {
    is_duplicate: u8,
    is_signer: u8,
    is_writable: u8,
    executable: u8,
    alignment: u32,
    key: [u8; 32],
    owner: [u8; 32],
    lamports: u64,
    data_len: usize,
    data: [u8; data_len],
    padding: [u8; 10_240],
    alignment_padding: [u8; ?],
    rent_epoch: i64,
}
```
- `is_duplicate`: 같은 계정이 목록에 두 번 이상 나타나면 건너뛰어 데이터를 "재직렬화"하지 않도록 하십시오. `0xFF`는 "고유함"을 의미합니다. 다른 값은 복사하는 인덱스입니다.
- `is_signer` / `is_writable` / `executable`: 프로그램이 추가 syscall 없이 로직과 CPI를 제어할 수 있도록 런타임에서 사용하는 단일 바이트 플래그입니다.
- `alignment`: 전체 구조체를 8바이트 정렬로 유지하는 자리 표시자 4바이트 슬롯입니다. Pinocchio는 realloc 중에 원래 데이터 길이를 추적하기 위해 용도를 변경합니다.
- `key` / `owner` / `lamports`: 각 계정이 가져야 하는 최소 실행 가능 데이터.
- `data_len` + `data`: 계정이 가질 수 있는 가변 길이 데이터.
- `padding`: 로더는 계정의 최대 크기인 10_240바이트를 미리 할당하므로 계정 데이터는 메모리를 이동하지 않고 제자리에서 변경되고 커질 수 있습니다.
- `align_padding`: 필요한 경우 추가 채우기. 다음 `AccountRaw`가 여전히 8바이트 경계에서 시작하도록 합니다(일반 eBPF 호스트에 중요).
- `rent_epoch`: 계정이 다음에 임대료를 지불해야 하는 에포크; 임대료 징수가 일시 중지되었음에도 호환성을 위해 유지됩니다.
