# 영구 위임자 확장 (The Permanent Delegate Extension)

`PermanentDelegate` 확장은 모든 토큰 계정에서 해당 민트의 토큰을 전송하거나 소각할 수 있는 민트의 모든 토큰에 대한 영구 위임자를 허용하는 `Mint` 계정 확장입니다.

<ArticleSection name="Mint 계정 초기화" id="initializing-the-mint-account" level="h2" />

`Mint` 계정에 `PermanentDelegate` 확장을 초기화하려면 `Anchor`가 우리를 위해 만든 매크로를 사용하기만 하면 됩니다.

영구 위임자 확장으로 민트를 만드는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateMint<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    #[account(
        init,
        payer = signer,
        mint::decimals = 6,
        mint::authority = signer.key(),
        mint::token_program = token_program
        extensions::permanent_delegate::delegate = signer,
    )]
    pub mint: InterfaceAccount<'info, Mint>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```

<ArticleSection name="허가된 작업" id="permissioned-actions" level="h2" />

취소할 수 있는 일반 위임자와 달리, 이 위임자 권한은 영구적이고 변경할 수 없습니다.

즉, `transfer()`, `burn()`, `approve()` 및 `freeze()`와 같은 모든 일반 작업은 실제 소유자의 서명 없이 권한자가 직접 필요할 때마다 실행할 수 있습니다.

즉, 일반적인 `transferChecked()`, `burnChecked()`, ... 명령어를 사용하고 `authority` 필드에 `PermanentDelegate` 권한을 전달하기만 하면 됩니다.
