# Token2022 프로그램 (The Token2022 Program)

![Token 2022 with Anchor](/graphics/course-banners/token-2022-with-anchor.png)

Token Extensions라고도 알려진 Token2022 프로그램은 Token 프로그램이 제공하는 기능의 상위 집합입니다.

어떤 추가 기능을 사용할 수 있는지, 레거시 토큰 프로그램과의 차이점이 무엇인지 자세히 알고 싶다면 [이 과정](/ko/courses/token-2022-program)을 따르십시오.

> Anchor에 익숙하지 않다면 진행하기 전에 [Anchor for Dummies](/ko/courses/anchor-for-dummies)를 살펴보는 것이 좋습니다.

Anchor의 경우 토큰과 관련된 모든 것은 `anchor-spl` crate에서 찾을 수 있습니다. 이러한 이유로 `Anchor` 작업 공간을 초기화한 후 다음을 수행하기만 하면 됩니다:

```bash
cargo add anchor-spl
```

> `anchor-spl` 버전은 `anchor-lang` crate와 동일해야 합니다. 그리고 token2022 확장은 버전 0.30.0 이후부터만 사용할 수 있습니다.

그런 다음 `idl-build = ["anchor-lang/idl-build", "anchor-spl/idl-build"]`를 사용하여 프로그램의 `Cargo.toml` 파일의 `[features]` 섹션에 있는 `idl-build` 기능을 업데이트하는 것을 잊지 마십시오.

<ArticleSection name="Mint 및 Token 계정" id="mint-and-token-accounts" level="h2" />

`Anchor`에 익숙하다면 계정 초기화와 관련된 많은 복잡성을 추상화하는 데 도움이 되는 일련의 매크로가 있다는 것을 알 것입니다.

여기서도 `Mint`, `Token` 및 `Associated Token` 계정에 대해 동일하게 작동합니다.

### 확장이 있는 Mint 계정

확장이 있는 `Mint` 계정은 크기가 다르고 다른 프로그램이 소유하기 때문에 `Anchor`는 `Mint` 계정이 레거시 토큰 또는 Token2022 프로그램의 계정인지 여부에 관계없이 독립적으로 작동하는 새로운 유형의 계정을 만들었습니다.

이를 사용하려면 다음과 같이 `anchor_spl::token_interface`에서 `TokenInterface`와 `Mint`를 모두 가져오기만 하면 됩니다:

```rust
use anchor_spl::token_interface::{TokenInterface, Mint};
```

그런 다음 `pub mint: InterfaceAccount<'info, Mint>,`를 수행하고 `mint::token_program = token_program`과 같이 계정 구조체에 있는 token_program 계정을 사용하도록 민트를 지정하면 됩니다!

> 토큰 인터페이스는 유형 안전성과 적절한 유효성 검사를 유지하면서 역직렬화 로직의 차이점을 처리할 필요 없이 두 유형의 계정과 상호 작용할 수 있는 공통 방식을 제공합니다.

민트 계정에 확장을 추가하는 방법을 알아보기 전에 Token2022 프로그램으로 민트를 만드는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateMint<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    #[account(
        init,
        payer = signer,
        mint::decimals = 6,
        mint::authority = signer.key(),
        mint::token_program = token_program
    )]
    pub mint: InterfaceAccount<'info, Mint>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```

이제 다행스럽게도 `Anchor`는 우리를 지원하며 다음과 같이 초기화 단계에서 가장 널리 사용되는 확장을 직접 추가할 수 있는 몇 가지 매크로를 만들었습니다:

```rust
#[account(
    // ...init
    extensions::metadata_pointer::authority = <target_account>,
    extensions::metadata_pointer::metadata_address = <target_account>,
    extensions::group_pointer::authority = <target_account>,
    extensions::group_pointer::group_address = <target_account>,
    extensions::group_member_pointer::authority = <target_account>,
    extensions::group_member_pointer::member_address = <target_account>,
    extensions::transfer_hook::authority = <target_account>,
    extensions::transfer_hook::program_id = <target_pubkey>
    extensions::close_authority::authority = <target_account>,
    extensions::permanent_delegate::delegate = <target_account>,
)]
pub mint: InterfaceAccount<'info, Mint>,
```

### 확장이 있는 연관 토큰 계정

`Associated Token` 계정에는 기본적으로 `ImmutableOwner` 확장이 함께 제공됩니다. 따라서 레거시 또는 Token2022 `Token Account` 생성의 유일한 차이점은 `Interface Account`를 사용한다는 것입니다.

연관 토큰 계정을 만드는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateAssociatedToken<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    pub mint: InterfaceAccount<'info, Mint>,
    #[account(
        mut,
        associated_token::mint = mint,
        associated_token::authority = signer,
        associated_token::token_program = token_program,
    )]
    pub associated_token: InterfaceAccount<'info, TokenAccount>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```

### 확장이 있는 토큰 계정

`Token` 계정에는 기본적으로 확장이 제공되지 않으며 도움이 되는 매크로도 없습니다. 따라서 매크로를 사용하면 일반 Token2022 `Token` 계정만 생성할 수 있습니다.

토큰 계정을 만드는 방법은 다음과 같습니다:

```rust
#[derive(Accounts)]
pub struct CreateToken<'info> {
    #[account(mut)]
    pub signer: Signer<'info>,
    pub mint: InterfaceAccount<'info, Mint>,
    #[account(
        mut,
        token::mint = mint,
        token::authority = signer,
        token::token_program = token_program,
    )]
    pub token: InterfaceAccount<'info, TokenAccount>,
    pub system_program: Program<'info, System>,
    pub token_program: Interface<'info, TokenInterface>,
}
```
