# 전송 명령어 (Transfer Instruction)

한 계정에서 다른 계정으로 토큰을 이동합니다. 이것은 사용자 간에 토큰을 보내는 기본 작업입니다.

토큰을 전송하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정.
- 전송하려는 수량 이상을 이미 보유하고 있는 소스 `Token` 계정 또는 `Associated Token` 계정.
- 소스 `Token` 계정으로부터 토큰을 받을 대상 `Token` 계정 또는 `Associated Token` 계정.

> 우리가 전송하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 전송하려면 실제로는 수량으로 `1e6`을 입력해야 합니다.

<ArticleSection name="Raw 명령어" id="raw-instruction" level="h2" />

추상화 없이 "raw" 명령어만 사용한다면, 토큰 전송은 다음과 같을 것입니다:

```ts
const destination = Keypair.generate();

const destinationTokenAccount = await getAssociatedTokenAddress(
    mint.publicKey,
    destination.publicKey,
);

// ATA 생성 명령어 생성
const createAtaInstruction = createAssociatedTokenAccountIdempotentInstruction(
    keypair.publicKey, // payer
    destinationTokenAccount, // associated token account address
    destination.publicKey, // owner
    mint.publicKey, // mint
);

// ATA로 토큰 전송
const transferInstruction = createTransferInstruction(
    sourceTokenAccount, // source token account pubkey
    destinationTokenAccount, // destination token account pubkey
    keypair.publicKey, // owner of the source token account
    1e6, // amount
);

const transaction = new Transaction().add(
    createAtaInstruction,
    transferInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token accounts created and tokens transferred! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 명령어" id="abstracted-instruction" level="h2" />

`transfer()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts
const destination = Keypair.generate();

const destinationAta = await getOrCreateAssociatedTokenAccount(
    connection,
    keypair,
    mint,
    destination.publicKey
);

console.log(`This is your ATA: ${destinationAta.address}!`)
  
let tx = await transfer(
    connection, // connection
    keypair, // payer
    sourceAta, // source token account
    destinationAta, // destination token account
    keypair.publicKey, // owner of the source token account
    1e6, // amount to transfer
);

console.log(`Succesfully Transferred!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
