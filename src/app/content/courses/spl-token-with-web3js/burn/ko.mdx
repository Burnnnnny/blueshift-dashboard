# 소각 명령어 (Burn Instruction)

유통에서 제거하여 토큰을 영구적으로 파괴합니다. 이는 토큰의 총 공급량을 줄입니다.

토큰을 소각하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정.
- 소각하려는 수량 이상을 이미 보유하고 있는 `Token` 계정 또는 `Associated Token` 계정.

> 우리가 소각하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 소각하려면 실제로는 수량으로 `1e6`을 입력해야 합니다.

<ArticleSection name="Raw 명령어" id="raw-instruction" level="h2" />

추상화 없이 "raw" 명령어만 사용한다면, 토큰 소각은 다음과 같을 것입니다:

```ts
// ATA의 토큰 소각
const burnInstruction = createBurnInstruction(
    tokenAccount, // token account
    mint, // mint
    keypair.publicKey // owner
    1e6, // amount
);

const transaction = new Transaction().add(burnInstruction);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Tokens Burned! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 명령어" id="abstracted-instruction" level="h2" />

`burn()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts  
let tx = await burn(
    connection, // connection
    keypair, // payer
    tokenAccount, // token account
    keypair.publicKey, // owner of the token account
    1e6, // amount to transfer
);

console.log(`Succesfully Burned!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
