# Mint To 명령어 (Mint To Instruction)

새로운 토큰을 생성하고 지정된 계정에 입금합니다. 오직 민트 권한(mint authority)만이 이 작업을 수행할 수 있습니다.

토큰을 발행(mint)하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- `mintAuthority`를 보유하고 있는 초기화된 `Mint` 계정
- 토큰을 발행할 초기화된 `Token` 계정 또는 `Associated Token` 계정

> 우리가 발행하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 발행하려면 실제로는 수량으로 `1e6`을 입력해야 합니다.

<ArticleSection name="Raw 명령어" id="raw-instruction" level="h2" />

추상화 없이 "raw" 명령어만 사용한다면, 토큰 발행은 다음과 같을 것입니다:

```ts
const destination = Keypair.generate();

const tokenAccount = await getAssociatedTokenAddress(
    mint.publicKey,
    destination.publicKey,
);

// ATA 생성 명령어 생성
const createAtaInstruction = createAssociatedTokenAccountIdempotentInstruction(
    keypair.publicKey, // payer
    tokenAccount, // associated token account address
    destination.publicKey, // owner
    mint.publicKey, // mint
);

// ATA에 토큰 발행
const mintToInstruction = createMintToInstruction(
    mint.publicKey, // mint
    tokenAccount, // destination
    keypair.publicKey, // mint authority
    1_000e6, // amount of tokens
);

const transaction = new Transaction().add(
    createAtaInstruction,
    mintToInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token accounts created and tokens minted! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 명령어" id="abstracted-instruction" level="h2" />

`mintTo()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts
const destination = Keypair.generate();

const ata = await getOrCreateAssociatedTokenAccount(
    connection,
    keypair,
    mint,
    destination.publicKey
);

console.log(`This is your ATA: ${ata.address}!`)
  
let tx = await mintTo(
    connection,
    keypair,
    mint,
    ata.address,
    keypair.publicKey,
    1e6,
);

console.log(`Succesfully Minted!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
