# 승인 및 철회 명령어 (Approve and Revoke Instructions)

승인(Approve)은 위임자(delegate)에게 계정 소유자를 대신하여 특정 수량의 토큰을 전송할 수 있는 권한을 부여합니다. 이를 통해 전체 계정 제어권을 주지 않고도 프로그래밍 방식의 토큰 전송이 가능해집니다.

> "승인된" 수량을 설정하며, 위임자는 그 수량까지만 전송할 수 있습니다.

철회(Revoke)는 계정에 대한 현재 위임자의 권한을 제거하여, 계정 소유자에게 전체 제어권을 반환합니다.

> 기존 위임을 즉시 취소하며, 오직 계정 소유자만이 위임을 철회할 수 있습니다(위임자 자체는 불가능).

토큰 계정을 위임하거나 철회하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정
- 제어권을 가져올 초기화된 `Token` 계정 또는 `Associated Token` 계정

> 우리가 승인하는 토큰의 양은 소수점(decimals)에 대해 "정규화"됩니다. 즉, 소수점 6자리를 가진 토큰 1개를 승인하려면 실제로는 수량으로 `1e6`을 입력해야 합니다.

<ArticleSection name="Raw 명령어" id="raw-instruction" level="h2" />

추상화 없이 "raw" 명령어만 사용한다면, 토큰 승인은 다음과 같을 것입니다:

```ts
const keypair = Keypair.generate();

const tokenAccount = await getAssociatedTokenAddress(
    mint.publicKey,
    keypair.publicKey,
);

// ATA 생성 명령어 생성
const createAtaInstruction = createAssociatedTokenAccountIdempotentInstruction(
    keypair.publicKey, // payer
    tokenAccount, // associated token account address
    destination.publicKey, // owner
    mint.publicKey, // mint
);

// ATA 위임
const approveInstruction = createApproveInstruction(
    tokenAccount // account
    delegate.publicKey, // delegate
    keypair.publickey // owner
    1e6, // amount of tokens
);

const transaction = new Transaction().add(
    createAtaInstruction,
    approveInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token accounts created and delegated! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

추상화 없이 "raw" 명령어만 사용한다면, 토큰 철회는 다음과 같을 것입니다:

```ts
// ATA의 위임 철회
const revokeInstruction = createRevokeInstruction(
    tokenAccount // account
    keypair.publickey // owner
);

const transaction = new Transaction().add(revokeInstruction);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token account delegate revoked! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 명령어" id="abstracted-instruction" level="h2" />

`approve()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts
const tokenAccount = Keypair.generate();

const ata = await getOrCreateAssociatedTokenAccount(
    connection,
    keypair,
    mint,
    tokenAccount.publicKey
);

console.log(`This is your ATA: ${ata.address}!`)
  
let tx = await approve(
    connection,
    keypair,
    ata.address, // token Account
    delegate-publicKey, // delegate
    keypair.publicKey, // owner
    1e6, // amount
);

console.log(`Succesfully Delegated!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```

`revoke()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts
let tx = await revoke(
    connection,
    keypair,
    ata.address, // token Account
    keypair.publicKey, // owner
);

console.log(`Succesfully Revoked Delegate!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
