# 동결 및 동결 해제 명령어 (Freeze and Thaw Instructions)

동결(Freeze)은 동결 해제될 때까지 계정의 모든 토큰 작업을 방지합니다. 오직 민트의 동결 권한(freeze authority)만이 이 작업을 수행할 수 있습니다.

> 전송, 승인, 소각을 완전히 비활성화하며 특정 동결된 계정에만 영향을 미칩니다.

동결 해제(Thaw)는 이전에 동결된 계정의 토큰 작업을 다시 활성화합니다. 오직 민트의 동결 권한만이 계정을 동결 해제할 수 있습니다.

> 동결된 계정의 전체 기능을 복원하며 민트의 동결 권한에 의해서만 수행될 수 있습니다.

토큰을 동결하거나 동결 해제하기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- `freezeAuthority`를 보유하고 있는 초기화된 `Mint` 계정
- 동결하거나 동결 해제하려는 초기화된 `Token` 계정 또는 `Associated Token` 계정

<ArticleSection name="Raw 명령어" id="raw-instruction" level="h2" />

추상화 없이 "raw" 명령어만 사용한다면, 토큰 동결은 다음과 같을 것입니다:

```ts
const keypair = Keypair.generate();

const tokenAccount = await getAssociatedTokenAddress(
    mint.publicKey,
    keypair.publicKey,
);

// ATA 생성 명령어 생성
const createAtaInstruction = createAssociatedTokenAccountIdempotentInstruction(
    keypair.publicKey, // payer
    tokenAccount, // associated token account address
    destination.publicKey, // owner
    mint.publicKey, // mint
);

// ATA 동결
const freezeInstruction = createFreezeAccountInstruction(
    tokenAccount // account
    mint // mint
    keypair.publickey // authority
);

const transaction = new Transaction().add(
    createAtaInstruction,
    freezeInstruction,
);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token accounts created and frozen! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

추상화 없이 "raw" 명령어만 사용한다면, 토큰 동결 해제는 다음과 같을 것입니다:

```ts
// ATA 동결 해제
const thawInstruction = createThawAccountInstruction(
    tokenAccount // account
    mint // mint
    keypair.publickey // authority
);

const transaction = new Transaction().add(thawInstruction);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token account thawed! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 명령어" id="abstracted-instruction" level="h2" />

`freezeAccount()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts
const tokenAccount = Keypair.generate();

const ata = await getOrCreateAssociatedTokenAccount(
    connection,
    keypair,
    mint,
    tokenAccount.publicKey
);

console.log(`This is your ATA: ${ata.address}!`)
  
let tx = await freezeAccount(
    connection,
    keypair,
    tokenAccount // account
    mint // mint
    keypair.publickey // authority
);

console.log(`Token Account succesfully Frozen!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```

`thawAccount()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts
let tx = await thawAccount(
    connection,
    keypair,
    tokenAccount // account
    mint // mint
    keypair.publickey // authority
);

console.log(`Token Account succesfully Thawed!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
