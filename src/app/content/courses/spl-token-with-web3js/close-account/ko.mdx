# 계정 닫기 명령어 (Close Account Instruction)

토큰 계정을 닫고 남은 SOL 임대료를 대상 계정으로 전송합니다. 네이티브 SOL 계정이 아닌 한 토큰 계정의 잔액은 0이어야 합니다.

> Token2022부터는 공급량이 0인 `Mint` 계정을 닫는 것이 가능합니다.

토큰 계정을 닫기 전에, 다음 사항이 이미 준비되어 있어야 합니다:
- 초기화된 `Mint` 계정
- 내부에 토큰이 없는 초기화된 `Token` 계정 또는 `Associated Token` 계정

<ArticleSection name="Raw 명령어" id="raw-instruction" level="h2" />

추상화 없이 "raw" 명령어만 사용한다면, 계정 닫기는 다음과 같을 것입니다:

```ts
// ATA 닫기
const closeAccountInstruction = createCloseAccountInstruction(
    tokenAccount // account
    keypair.publickey // destination
    keypair.publickey // authority
);

const transaction = new Transaction().add(closeAccountInstruction);

const signature = await sendAndConfirmTransaction(connection, transaction, [keypair]);

console.log(`Token accounts closed! Check out your TX here: https://explorer.solana.com/tx/${signature}?cluster=devnet`);
```

<ArticleSection name="추상화된 명령어" id="abstracted-instruction" level="h2" />

`closeAccount()` 명령어를 사용하여 추상화된 동일한 명령어는 다음과 같습니다:

```ts
  let tx = await closeAccount(
    connection,
    keypair,
    ata.address, // token Account
    keypair.publicKey, // destination
    keypair.publicKey, // authority
);

console.log(`Succesfully Closed!. Transaction Here: https://explorer.solana.com/tx/${tx}?cluster=devnet`)
```
