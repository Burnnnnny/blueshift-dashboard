# 중복 변경 가능 계정 (Duplicate Mutable Accounts)

중복 변경 가능 계정 공격은 동일한 유형의 여러 변경 가능 계정을 허용하는 프로그램을 악용하여 동일한 계정을 두 번 전달함으로써 프로그램이 자신도 모르게 자체 변경 사항을 덮어쓰도록 합니다. 이는 단일 명령어 내에서 나중의 변경이 이전 변경을 조용히 취소할 수 있는 경합 조건을 생성합니다.

이 취약점은 주로 lamport 전송과 같은 시스템 작업이 아니라 프로그램 소유 계정의 데이터를 수정하는 명령어에 영향을 미칩니다. 공격은 Solana의 런타임이 동일한 계정이 다른 파라미터에 여러 번 전달되는 것을 막지 않기 때문에 성공합니다. 중복을 감지하고 처리하는 것은 프로그램의 책임입니다.

위험은 명령어 실행의 순차적 특성에 있습니다. 동일한 계정이 두 번 전달되면 프로그램은 첫 번째 변형을 수행한 다음 즉시 두 번째 변형으로 덮어쓰므로 계정이 사용자의 의도나 프로그램의 논리를 반영하지 않을 수 있는 예상치 못한 상태로 남게 됩니다.

두 프로그램 계정의 소유권 필드를 업데이트하는 이 취약한 명령어를 고려하십시오:

```rust
#[program]
pub mod unsafe_update_account{
    use super::*;
    
    //..

    pub fn update_account(ctx: Context<UpdateAccount>, pubkey_a: Pubkey, pubkey_b: Pubkey) -> Result<()> {
        ctx.accounts.program_account_1.owner = pubkey_a;
        ctx.accounts.program_account_2.owner = pubkey_b;
        
        Ok(())
    }

    //..

}

#[derive(Accounts)]
pub struct UpdateAccount<'info> {
   #[account(mut)]
    pub program_account_1: Account<'info, ProgramAccount>,
    #[account(mut)]
    pub program_account_2: Account<'info, ProgramAccount>,
}

#[account]
pub struct ProgramAccount {
    owner: Pubkey,
}
```

이 코드에는 치명적인 결함이 있습니다. `program_account_1`과 `program_account_2`가 다른 계정인지 확인하지 않습니다.

공격자는 두 파라미터에 대해 동일한 계정을 전달하여 이를 악용할 수 있습니다. 일어나는 일은 다음과 같습니다:
- 프로그램이 `program_account_1.owner = pubkey_a`로 설정합니다.
- 두 파라미터가 동일한 계정을 참조하므로 프로그램은 즉시 `program_account_2.owner = pubkey_b`로 덮어씁니다.

최종 결과: 계정의 소유자가 `pubkey_b`로 설정되어 `pubkey_a`를 완전히 무시합니다.

이것은 무해해 보일 수 있지만 그 의미를 고려하십시오. 특정 소유권 할당으로 두 개의 서로 다른 계정을 업데이트할 것으로 예상하는 사용자는 하나의 계정만 수정되었으며 의도한 방식이 아님을 발견합니다. 복잡한 프로토콜에서 이는 일관성 없는 상태, 실패한 다단계 작업 또는 금전적 손실로 이어질 수 있습니다.

해결책은 간단합니다. 진행하기 전에 계정이 고유한지 확인하기만 하면 됩니다:

```rust
pub fn update_account(ctx: Context<UpdateAccount>, pubkey_a: Pubkey, pubkey_b: Pubkey) -> Result<()> {
    if ctx.accounts.program_account_1.key() == ctx.accounts.program_account_2.key() {
        return Err(ProgramError::InvalidArgument)
    }

    ctx.accounts.program_account_1.owner = pubkey_a;
    ctx.accounts.program_account_2.owner = pubkey_b;

    Ok(())
}
```
