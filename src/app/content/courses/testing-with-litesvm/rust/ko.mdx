# Rust를 사용한 LiteSVM (LiteSVM with Rust)

`litesvm` 패키지는 계정 상태를 직접 조작하고 프로그램에 대해 트랜잭션을 실행할 수 있는 가벼운 Solana 환경을 만들기 위한 핵심 테스트 인프라를 제공합니다.

<ArticleSection name="첫 단계" id="first-steps" level="h2" />

프로젝트에 LiteSVM을 추가하십시오:

```bash
cargo add --dev litesvm
```

<ArticleSection name="LiteSVM 기초" id="basics" level="h2" />

프로그램 ID를 선언하고 LiteSVM 인스턴스를 생성하는 것으로 시작하십시오.

테스트 중에 트랜잭션이 올바르게 실행되고 `ProgramMismatch` 오류가 발생하지 않도록 프로그램에서 정의한 것과 똑같은 프로그램 ID를 사용하십시오:

```rust
use litesvm::LiteSVM;
use solana_pubkey::{pubkey, Pubkey};

const program_id: Pubkey = pubkey!("22222222222222222222222222222222222222222222");

#[test]
fn test() {
    // LiteSVM의 새 인스턴스 생성
    let mut svm = LiteSVM::new();

    // 올바른 공개 키로 프로그램 로드
    svm.add_program_from_file(program_id, "target/deploy/program.so");
}
```

테스트를 실행하려면 트랜잭션 객체를 생성하고 `.send_transaction(tx)` 함수를 사용하십시오:

```rust
use litesvm::LiteSVM;
use solana_transaction::Transaction;

#[test]
fn test() {
    // LiteSVM의 새 인스턴스 생성
    let mut svm = LiteSVM::new();

    // 새 트랜잭션 생성
    let mut tx = Transaction::new_signed_with_payer(
        &[...ixs],
        Some(&payer.pubkey()),
        &[...signersKeypair],
        svm.latest_blockhash(),
    );

    // 트랜잭션 전송
    let result = svm.send_transaction(tx).unwrap();
}
```

<ArticleSection name="계정 (Accounts)" id="accounts" level="h2" />

LiteSVM으로 Solana 프로그램을 테스트할 때 실제 프로그램 실행 시나리오를 반영하는 여러 유형의 계정으로 작업하게 됩니다.

이러한 계정을 올바르게 구성하는 방법을 이해하는 것은 효과적인 테스트에 필수적입니다.

### 시스템 계정

가장 기본적인 계정 유형은 시스템 계정이며 두 가지 주요 변형이 있습니다:
- **지불자 계정 (Payer accounts)**: 프로그램 계정 생성 또는 lamport 전송에 자금을 지원하는 lamport가 있는 계정
- **초기화되지 않은 계정 (Uninitialized accounts)**: lamport가 없는 빈 계정으로, 일반적으로 초기화를 기다리는 프로그램 계정을 나타내는 데 사용됩니다.

시스템 계정에는 데이터가 없으며 시스템 프로그램이 소유합니다. 지불자와 초기화되지 않은 계정의 주요 차이점은 lamport 잔액입니다. 지불자는 자금이 있는 반면 초기화되지 않은 계정은 비어 있습니다.

LiteSVM에서 `payer` 계정을 만드는 방법은 다음과 같습니다:

```rust
use litesvm::LiteSVM;
use solana_account::Account;
use solana_keypair::Keypair;
use solana_pubkey::{pubkey, Pubkey};

#[test]
fn test() {
    // LiteSVM의 새 인스턴스 생성
    let mut svm = LiteSVM::new();

    // 새 계정 생성
    let account = Keypair::new();

    // 수정된 데이터로 계정 추가
    svm.set_account(
        account.pubkey(),
        Account {
            lamports: 100_000_000,
            data: [],
            owner: ID,
            executable: false,
            rent_epoch: 0,
        },
    );
}
```

> 초기화되지 않은 계정은 `Keypair.generate()`로 생성된 일반 계정일 뿐입니다. 추가 설정이 필요하지 않습니다.

### 프로그램 계정

사용자 지정 데이터 구조를 포함하는 프로그램 계정의 경우 유사한 접근 방식을 사용할 수 있습니다.
또한 계정 데이터를 바이트 배열로 직렬화해야 하며, 이는 수동으로 수행하거나 `borsh`, `bincode` 또는 `solana_program_pack`과 같은 라이브러리를 사용하여 수행할 수 있습니다.

```rust
use litesvm::LiteSVM;
use solana_account::Account;
use solana_keypair::Keypair;
use solana_pubkey::{pubkey, Pubkey};

#[test]
fn test() {
    // LiteSVM의 새 인스턴스 생성
    let mut svm = LiteSVM::new();

    // 새 계정 생성
    let account = Keypair::new();

    let mut account_data = [0; SIZE_OF_THE_ACCOUNT];

    // 위에서 정의한 바이트 배열로 계정 데이터 직렬화
    // ...

    let lamports = svm.minimum_balance_for_rent_exemption(SIZE_OF_THE_ACCOUNT);

    // 수정된 데이터로 계정 추가
    svm.set_account(
        account.pubkey(),
        Account {
            lamports,
            data: account_data,
            owner: ID,
            executable: false,
            rent_epoch: 0,
        },
    )
}
```

> 테스트에서는 정확한 임대료를 계산할 필요가 없습니다. 실제 자금이 아니므로 lamport를 `100_000_000_000`과 같은 큰 값으로 설정하고 임대료 계산을 건너뛸 수 있습니다.

### 토큰 계정

SPL 토큰 계정의 데이터를 직렬화하려면 `solana_program_pack::Pack`을 구현하는 `spl_token::Mint` 및 `spl_token::Account`를 사용할 수 있습니다.

```rust
use litesvm::LiteSVM;
use solana_keypair::Keypair;
use solana_pubkey::{pubkey, Pubkey};
use solana_account::Account;
use spl_token::{ID as TOKEN_PROGRAM_ID, state::{Mint, Account as TokenAccount}};
use solana_program_pack::Pack;

#[test]
fn test() {
    // LiteSVM의 새 인스턴스 생성
    let mut svm = LiteSVM::new();

    // 새 민트 계정 생성
    let mint = Keypair::new();

    // 민트 계정 데이터 채우기
    let mint_data = Mint {
        mint_authority: None.into(),
        supply: 0,
        decimals: 6,
        is_initialized: true,
        freeze_authority: None.into(),
    };

    let mut mint_account_data = vec![0; Mint::LEN];
    Mint::pack(mint_data, &mut mint_account_data).unwrap();

    // 임대 면제를 위해 최소 lamport 금액 가져오기
    let lamports = svm.minimum_balance_for_rent_exemption(Mint::LEN);

    // 민트 계정 추가
    svm.set_account(
        mint.pubkey(),
        Account {
            lamports,
            data: mint_account_data,
            owner: TOKEN_PROGRAM_ID,
            executable: false,
            rent_epoch: 0,
        },
    );

    // 새 민트 계정 생성
    let token_account = Keypair::new();
    let owner = Keypair::new();

    // 토큰 계정 데이터 채우기
    let token_account_data = TokenAccount {
        mint: mint.pubkey(),
        owner: owner.pubkey(),
        amount: 0,
        delegate: None.into(),
        state: spl_token::state::AccountState::Initialized,
        is_native: None.into(),
        delegated_amount: 0,
        close_authority: None.into(),
    };

    let mut token_account_data_bytes = vec![0; TokenAccount::LEN];
    TokenAccount::pack(token_account_data, &mut token_account_data_bytes).unwrap();

    // 임대 면제를 위해 최소 lamport 금액 가져오기
    let lamports = svm.minimum_balance_for_rent_exemption(TokenAccount::LEN);

    // 토큰 계정 추가
    svm.set_account(
        token_account.pubkey(),
        Account {
            lamports,
            data: token_account_data_bytes,
            owner: TOKEN_PROGRAM_ID,
            executable: false,
            rent_epoch: 0,
        },
    );
}
```

<ArticleSection name="실행 (Execution)" id="execution" level="h2" />

계정을 생성하고 LiteSVM 인스턴스에 추가했으므로 이제 트랜잭션을 보낼 수 있고 프로그램 로직을 검증할 수 있습니다.

트랜잭션을 보내기 전에 결과를 시뮬레이션할 수 있습니다:

```rust
let simulated_result = svm.simulate_transaction(tx);
```

그런 다음 트랜잭션을 보내고 로그를 검사합니다:

```rust
let result = svm.send_transaction(tx);
let logs = result.logs;
```

### 고급 기능

실행 전후에 LiteSVM 인스턴스에 포함된 전체 원장을 읽을 수 있고 사용자 정의할 수 있습니다.

시계와 같은 sysvar 값을 조작할 수 있습니다:

```rust
// 시계 변경
let mut new_clock = svm.get_sysvar::<Clock>();
new_clock.unix_timestamp = 1735689600;
svm.set_sysvar::<Clock>(&new_clock);

// 특정 슬롯으로 점프
svm.warp_to_slot(500);

// 현재 블록해시 만료
svm.expire_blockhash();
```

계정 및 프로토콜 데이터를 읽을 수도 있습니다:

```rust
// 계정에 대한 모든 정보 가져오기 (데이터, lamport, 소유자, ...)
svm.get_account(&account.publickey);

// 계정의 lamport 잔액 가져오기
svm.get_balance(&account.publickey);

// 지금까지 사용된 컴퓨팅 단위 수 가져오기
svm.get_compute_budget();
```

또는 런타임 동작 방식을 구성합니다:

```rust
// 컴퓨팅 예산 설정
let compute_budget = ComputeBudget::default();
compute_budget.compute_unit_limit = 2_000_000;
svm.with_compute_budget(compute_budget);

// Sigverify를 활성으로 설정
svm.with_sigverify(true);

// 블록해시 확인을 활성으로 설정
svm.with_blockhash_check(true);

// 기본 Sysvars 설정
svm.with_sysvars();

// 사용할 FeatureSet 설정
svm.with_feature_set(FeatureSet::default())
```
