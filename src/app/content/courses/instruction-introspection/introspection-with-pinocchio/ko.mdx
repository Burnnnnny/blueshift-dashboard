# Pinocchio를 활용한 명령어 내부 검사 (Instruction Introspection with Pinocchio)

Pinocchio는 `solana_program` 크레이트와 다른 타입을 사용합니다. 즉, 우리는 Pinocchio에 최적화된 새로운 SDK를 만들어야 했습니다.

[Orion](https://x.com/BasedOrion_)의 도움으로, 우리는 "원본" 구현을 존중하면서도 가장 비싼 sysvar 중 하나인 `Instruction` sysvar를 가장 효율적인 것 중 하나로 만드는 헬퍼 세트를 만들었습니다.

이러한 이유로, 우리는 외부 크레이트를 설치하지 않고도 Pinocchio에서 *명령어 내부 검사*를 사용할 수 있으며, 이 함수들을 가져와서 필요한 모든 정보에 접근할 수 있습니다:

```rust
use pinocchio::sysvars::instructions::Instructions;
```

<ArticleSection name="내부 검사 사용 방법" id="how-to-use-introspection" level="h2" />

앞서 언급했듯이, 명령어 내부 검사는 `Instruction` sysvar 계정의 데이터를 역직렬화하여 명령어에 대해 필요한 모든 데이터를 제공하는 것입니다.

우리는 현재 인덱스를 확인하는 것으로 시작합니다. 다음과 같이 `load_current_index_checked` 함수를 사용하여 이를 수행할 수 있습니다:

```rust
let instruction_sysvar = unsafe { Instructions::new_unchecked(&self.accounts.sysvar_instructions.try_borrow_data()?) };
let index = instruction_sysvar.load_current_index();
```

그 후, `load_instruction_at_checked`를 사용하여 상대적 인덱스에 있는 명령어를 확인할 수 있습니다. 이번에는 내부 검사를 수행하는 명령어 바로 다음에 오는 명령어를 확인합니다:

```rust
// 다음 명령어를 로드하며, 이는 올바른 입력인지 확인하고자 하는 명령어입니다.
let instruction = instruction_sysvar.load_instruction_at(index as usize + 1)?;
```

다음 단계로 넘어가기 전에, 악의적인 공격을 방지하는 데 필수적인 정보가 무엇인지 자문해봐야 합니다.

우리는 보통 사용되는 프로그램이 우리가 예상하는 것인지 확인하는 것으로 시작합니다. 이 예제에서는 시스템 프로그램의 다른 명령어를 검사하고 있으므로 다음과 같이 할 수 있습니다:

```rust
if instruction.get_program_id() != &pinocchio_system::ID {
    return Err(ProgramError::InvalidInstructionData);
}
```

다음으로, 명령어가 우리가 예상하는 것인지 확인합니다. 그렇게 하려면 구별자와 명령어 데이터를 예상 값과 비교합니다. `instruction_data` 변수를 생성하고 다음과 같이 비교하는 것으로 시작합니다:

```rust
let mut instruction_data = [0u8; 12];
instruction_data[0..4].copy_from_slice(&2u32.to_le_bytes());
instruction_data[4..12].copy_from_slice(&100_000_000u64.to_le_bytes());

if instruction.get_instruction_data() != instruction_data {
    return Err(ProgramError::InvalidInstructionData);
}
```

그런 다음 확인 중인 명령어의 로직에 따라 더 많은 프로그램별 검사를 수행할 수 있습니다.

또한 검사된 명령어에 있는 계정을 확인할 수 있습니다. 이 단계는 계정 구조체의 정확한 구조를 알아야 합니다. 특정 인덱스에 있는 계정의 데이터나 공개 키를 요청할 것이기 때문입니다:

```rust
if !pubkey_eq(instruction.get_account_meta_at(0)?.key(), self.accounts.from.key()) {
    return Err(ProgramError::InvalidAccountData);
}
```
