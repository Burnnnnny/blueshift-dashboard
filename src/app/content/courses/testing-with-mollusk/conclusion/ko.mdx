# 결론 (Conclusion)

축하합니다! Mollusk 테스트 과정을 완료했습니다. 이제 빠른 실행, 정밀한 제어 및 상세한 성능 통찰력을 제공하는 Solana 프로그램을 위한 강력한 경량 테스트 프레임워크인 Mollusk를 사용하는 방법을 포괄적으로 이해하게 되었습니다.

<ArticleSection name="배운 내용" id="what-you-learned" level="h2" />

이 과정 전반에 걸쳐 다음에 대한 필수 지식을 얻었습니다:
- Mollusk가 로우 레벨 Solana 가상 머신(SVM) 구성 요소를 사용하여 간소화된 테스트 환경을 제공하는 방법
- 전체 검증기 시뮬레이션에 비해 Mollusk의 경량 접근 방식의 장점
- 핵심 `mollusk-svm` crate 및 프로그램별 헬퍼로 Mollusk 설정
- 단일 및 연결된 명령어 테스트를 위해 Mollusk의 4가지 주요 실행 API 사용
- 성공 조건, 컴퓨팅 단위 및 계정 상태에 대한 포괄적인 검증 검사 구현
- 미리 초기화된 토큰 계정(Mint, 토큰 계정, 연결된 토큰 계정) 생성
- `MolluskComputeUnitBencher`를 사용하여 컴퓨팅 단위 소비 벤치마킹
- 특수 기능을 위한 사용자 지정 시스템 호출 개발 및 테스트
- 컴퓨팅 예산, 기능 세트 및 sysvar을 통해 실행 환경 사용자 지정

<ArticleSection name="다음 단계" id="next-steps" level="h2" />

이제 Mollusk를 사용하여 강력하고 잘 테스트된 Solana 프로그램을 구축할 수 있는 지식을 갖추게 되었습니다! 다음은 권장되는 다음 단계입니다:

1. 실제 프로그램으로 연습: Mollusk 지식을 적용하여 [Anchor 프로그램](/ko/courses/anchor-for-dummies/testing-your-program#mollusk-tests) 또는 [Pinocchio 프로그램](/ko/courses/introduction-to-pinocchio/testing-your-program#mollusk-tests)을 테스트하십시오.
2. 도전 과제 탐색: Mollusk 테스트 기술을 적용하는 데 도움이 되는 실습 연습을 위해 [도전 과제 섹션](/ko/challenges)을 방문하십시오.
3. 커뮤니티 참여: Mollusk를 사용하는 다른 개발자와 연결하여 디스코드에서 테스트 전략 및 모범 사례를 공유하십시오.
4. 업데이트 유지: 최신 기능 및 개선 사항에 대해서는 [Mollusk 리포지토리](https://github.com/anza-xyz/mollusk)를 팔로우하십시오.
