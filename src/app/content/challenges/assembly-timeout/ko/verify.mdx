<ChallengeTitle>sBPF 어셈블리 타임아웃 (sBPF Assembly Timeout)</ChallengeTitle>

이제 어셈블리 작성에 익숙해졌으므로 `sol_get_clock_sysvar`를 사용하는 대신 `Clock` 계정을 전달하여 동일한 목표를 달성해 보세요.

하나의 명령어만 있는 프로그램을 만드세요. 다음을 수행해야 합니다:
- `Clock` 계정(크기 40)을 입력받습니다.
- 명령어 데이터에서 u64(8바이트) 슬롯을 입력받습니다.
- `Clock` 계정의 처음 8바이트를 사용하여 현재 슬롯을 가져옵니다.
- 현재 슬롯이 명령어에 전달된 슬롯보다 큰지 확인합니다. 그렇다면 오류 코드 1을 반환합니다.

> 올바른 명령어 데이터 오프셋을 얻으려면 [도구](https://sbpf.xyz)를 사용할 수 있습니다. 계정을 하나 추가하고 데이터 길이를 40으로 설정하는 것을 잊지 마세요!

[어셈블리 소개 과정의 도구 섹션](/ko/courses/introduction-to-assembly/tooling)에 설명된 대로 sBPF 패키지를 설치하는 것으로 시작하고 터미널에서 다음 명령을 사용하여 프로그램을 빌드하세요:

```
sbpf build
```

그러면 `target/deploy` 폴더에 `.so` 파일이 생성됩니다.

이제 `take challenge` 버튼을 클릭하고 거기에 파일을 놓으세요!
