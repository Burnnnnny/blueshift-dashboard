# 인출 (Withdraw)

`withdraw` 명령어는 세 가지 주요 작업을 수행합니다:
- 사용자가 `burn`하려는 LP 양에 따라 `mint_x` 및 `mint_y` 토큰을 인출합니다.
- 인출할 금액을 계산하고 사용자가 지정한 `mint_x` 및 `mint_y`보다 적지 않은지 확인합니다.
- 사용자 ata에서 적절한 양의 `mint_lp`를 소각합니다.

> `initialize` 명령어 섹션에서 언급했듯이 최적화를 위해 명령어 외부에서 모든 `Associated Token Accounts`를 초기화할 것입니다.

<ArticleSection name="필수 계정" id="required-accounts" level="h2" />

이 컨텍스트에 필요한 계정은 다음과 같습니다:
- `user`: Amm의 유동성으로 토큰을 인출하는 사용자입니다. `signer`여야 합니다.
- `mint_lp`: 풀의 유동성을 나타내는 Mint 계정입니다. `mutable`로 전달되어야 합니다.
- `vault_x`: 풀에 예치된 모든 토큰 X를 보유하는 토큰 계정입니다. `mutable`로 전달되어야 합니다.
- `vault_y`: 풀에 예치된 모든 토큰 Y를 보유하는 토큰 계정입니다. `mutable`로 전달되어야 합니다.
- `user_x_ata`: 토큰 X에 대한 사용자의 연결된 토큰 계정입니다. 사용자의 토큰 X가 풀에서 전송되는 대상 계정입니다. `mutable`로 전달되어야 합니다.
- `user_y_ata`: 토큰 Y에 대한 사용자의 연결된 토큰 계정입니다. 사용자의 토큰 Y가 풀에서 전송되는 대상 계정입니다. `mutable`로 전달되어야 합니다.
- `user_lp_ata`: LP 토큰에 대한 사용자의 연결된 토큰 계정입니다. LP 토큰이 소각될 소스 계정입니다. `mutable`로 전달되어야 합니다.
- `config`: AMM 풀의 구성 계정입니다. 모든 관련 풀 매개변수와 상태를 저장합니다.
- `token program`: SPL Token 프로그램 계정입니다. 전송 및 발행과 같은 토큰 작업을 수행하는 데 필요합니다. `executable`이어야 합니다.

여기서도 구현은 여러분에게 맡기겠습니다:


<ArticleSection name="명령어 데이터" id="instruction-data" level="h2" />

전달해야 할 명령어 데이터는 다음과 같습니다:
- `amount`: 사용자가 소각하려는 LP 토큰의 양. `[u64]`여야 합니다.
- `min_x`: 사용자가 인출할 의향이 있는 토큰 X의 최소 양. `[u64]`여야 합니다.
- `min_y`: 사용자가 인출할 의향이 있는 토큰 Y의 최소 양. `[u64]`여야 합니다.
- `expiration`: 이 주문의 만료. 트랜잭션이 일정 시간 내에 실행되도록 하는 데 중요합니다. `[i64]`여야 합니다.

초기화와 동일하게 `WithdrawInstructionData`에 대한 구현을 처리할 것입니다. 따라서 구현은 여러분에게 맡기겠습니다:

```rust
pub struct WithdrawInstructionData {
    pub amount: u64,
    pub min_x: u64,
    pub min_y: u64,
    pub expiration: i64,
}

impl<'a> TryFrom<&'a [u8]> for WithdrawInstructionData {
    type Error = ProgramError;

    fn try_from(data: &'a [u8]) -> Result<Self, Self::Error> {
        //..
    }
}
```

> `amount`, `min_y`, `min_x`와 같은 금액이 0보다 크고 `Clock` sysvar를 사용하여 주문이 아직 만료되지 않았는지 확인하세요.

<ArticleSection name="명령어 로직" id="instruction-logic" level="h2" />

`instruction_data`와 `accounts`를 모두 역직렬화하는 것으로 시작합니다.

그런 다음 다음을 수행해야 합니다:
- `Config` 계정을 로드하여 그 안의 모든 데이터를 가져옵니다. `Config::load()` 도우미를 사용하여 수행할 수 있습니다.
- `AmmState`가 유효한지 확인합니다(`AmmState::Disabled`와 같지 않은 경우).
- `vault_x`와 `vault_y`의 파생이 연결된 토큰 계정인지 확인합니다.
- 관련된 모든 토큰 계정을 역직렬화하고 그 안의 데이터를 사용하여 `constant-product-curve` 크레이트를 사용하여 인출할 금액을 계산하고 다음과 같이 슬리피지를 확인합니다:
```rust
let mint_lp = unsafe { Mint::from_account_info_unchecked(self.accounts.mint_lp)? };
let vault_x = unsafe { TokenAccount::from_account_info_unchecked(self.accounts.vault_x)? };
let vault_y = unsafe { TokenAccount::from_account_info_unchecked(self.accounts.vault_y)? };

let (x, y) = match mint_lp.supply() == self.instruction_data.amount {
    true => (vault_x.amount(), vault_y.amount()),
    false => {
        let amounts = ConstantProduct::xy_withdraw_amounts_from_l(
            vault_x.amount(),
            vault_y.amount(),
            mint_lp.supply(),
            self.instruction_data.amount,
            6,
        )
        .map_err(|_| ProgramError::InvalidArgument)?;

        (amounts.x, amounts.y)
    }
};

// Check for slippage
if !(x >= self.instruction_data.min_x && y >= self.instruction_data.min_y) {
    return Err(ProgramError::InvalidArgument);
}
```
- 보관소에서 사용자의 토큰 계정으로 금액을 이체하고 사용자 토큰 계정에서 적절한 양의 LP 토큰을 소각합니다.

> `vault_x`와 `vault_y`의 `authority`는 `config` 계정입니다.

이 작업을 스스로 수행할 수 있을 만큼 능숙해야 하므로 구현은 여러분에게 맡기겠습니다:

```rust
pub struct Withdraw<'a> {
    pub accounts: WithdrawAccounts<'a>,
    pub instruction_data: WithdrawInstructionData,
}

impl<'a> TryFrom<(&'a [u8], &'a [AccountInfo])> for Withdraw<'a> {
    type Error = ProgramError;

    fn try_from((data, accounts): (&'a [u8], &'a [AccountInfo])) -> Result<Self, Self::Error> {
        let accounts = WithdrawAccounts::try_from(accounts)?;
        let instruction_data = WithdrawInstructionData::try_from(data)?;

        // Return the initialized struct
        Ok(Self {
            accounts,
            instruction_data,
        })
    }
}

impl<'a> Withdraw<'a> {
    pub const DISCRIMINATOR: &'a u8 = &2;

    pub fn process(&mut self) -> ProgramResult {
        //..

        Ok(())
    }
}
```
