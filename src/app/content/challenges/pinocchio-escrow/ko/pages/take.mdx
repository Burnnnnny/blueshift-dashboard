# 수락 (Take)

`take` 명령어는 스왑을 마무리합니다:
  - 에스크로 레코드를 닫고 임대료 lamports를 메이커에게 돌려보냅니다.
  - 토큰 A를 보관소에서 테이커에게 이동한 다음 보관소를 닫습니다.
  - 합의된 양의 토큰 B를 테이커에서 메이커에게 이동합니다.

<ArticleSection name="필수 계정" id="required-accounts" level="h2" />

이 컨텍스트에 필요한 계정은 다음과 같습니다:

- taker: 거래를 수락하려는 사람. 서명자이자 가변이어야 함.
- maker: 에스크로의 생성자. 가변이어야 함.
- escrow: 초기화하려는 에스크로 계정. 가변이어야 함.
- mint_a: 에스크로에 예치하는 토큰
- mint_b: 받기를 원하는 토큰
- vault: 에스크로가 소유한 연결된 토큰 계정. 가변이어야 함
- taker_ata_a: mint_a에 대해 테이커가 소유한 연결된 토큰 계정. 가변이어야 함
- taker_ata_b: mint_b에 대해 테이커가 소유한 연결된 토큰 계정. 가변이어야 함
- maker_ata_b: mint_b에 대해 메이커가 소유한 연결된 토큰 계정. 가변이어야 함
- system_program: 시스템 프로그램. 실행 가능이어야 함
- token_program: 토큰 프로그램. 실행 가능이어야 함

그리고 우리는 이것에 대해 다음과 같은 검사를 수행합니다:

```rust
pub struct TakeAccounts<'a> {
  pub taker: &'a AccountInfo,
  pub maker: &'a AccountInfo,
  pub escrow: &'a AccountInfo,
  pub mint_a: &'a AccountInfo,
  pub mint_b: &'a AccountInfo,
  pub vault: &'a AccountInfo,
  pub taker_ata_a: &'a AccountInfo,
  pub taker_ata_b: &'a AccountInfo,
  pub maker_ata_b: &'a AccountInfo,
  pub system_program: &'a AccountInfo,
  pub token_program: &'a AccountInfo,
}

impl<'a> TryFrom<&'a [AccountInfo]> for TakeAccounts<'a> {
  type Error = ProgramError;

  fn try_from(accounts: &'a [AccountInfo]) -> Result<Self, Self::Error> {
    let [taker, maker, escrow, mint_a, mint_b, vault, taker_ata_a, taker_ata_b, maker_ata_b, system_program, token_program, _] = accounts else {
      return Err(ProgramError::NotEnoughAccountKeys);
    };

    // Basic Accounts Checks
    SignerAccount::check(taker)?;
    ProgramAccount::check(escrow)?;
    MintInterface::check(mint_a)?;
    MintInterface::check(mint_b)?;
    AssociatedTokenAccount::check(taker_ata_b, taker, mint_b, token_program)?;
    AssociatedTokenAccount::check(vault, escrow, mint_a, token_program)?;

    // Return the accounts
    Ok(Self {
      taker,
      maker,
      escrow,
      mint_a,
      mint_b,
      taker_ata_a,
      taker_ata_b,
      maker_ata_b,
      vault,
      system_program,
      token_program,
    })
  }
}
```

<ArticleSection name="명령어 데이터" id="instruction-data" level="h2" />

로직을 수행하는 데 필요한 모든 데이터는 이미 에스크로 계정이나 역직렬화하는 계정에 있습니다. 따라서 이 명령어에는 `instruction_data`가 필요하지 않습니다.

<ArticleSection name="명령어 로직" id="instruction-logic" level="h2" />

계정을 역직렬화한 후 `TryFrom` 구현에서 필수 계정을 초기화하는 것으로 시작합니다.

이 단계에서는 테이커의 토큰 A 계정과 메이커의 토큰 B 계정이 이미 존재하는지 확신할 수 없으므로 `AssociatedTokenAccount::init_if_needed`를 사용하여 초기화되도록 합니다.

```rust
pub struct Take<'a> {
  pub accounts: TakeAccounts<'a>,
}

impl<'a> TryFrom<&'a [AccountInfo]> for Take<'a> {
  type Error = ProgramError;
  
  fn try_from(accounts: &'a [AccountInfo]) -> Result<Self, Self::Error> {
    let accounts = TakeAccounts::try_from(accounts)?;

    // Initialize necessary accounts
    AssociatedTokenAccount::init_if_needed(
      accounts.taker_ata_a,
      accounts.mint_a,
      accounts.taker,
      accounts.taker,
      accounts.system_program,
      accounts.token_program,
    )?;

    AssociatedTokenAccount::init_if_needed(
      accounts.maker_ata_b,
      accounts.mint_b,
      accounts.taker,
      accounts.maker,
      accounts.system_program,
      accounts.token_program,
    )?;

    Ok(Self {
      accounts,
    })
  }
}
```

이제 다음을 수행할 로직 자체에 집중할 수 있습니다:
- `taker_ata_b`에서 `maker_ata_b`로 토큰을 전송합니다.
- `vault`에서 `taker_ata_a`로 토큰을 전송합니다.
- 현재 비어 있는 `vault`를 닫고 계정에서 임대료를 인출합니다.

```rust
impl<'a> Take<'a> {
  pub const DISCRIMINATOR: &'a u8 = &1;
  
  pub fn process(&mut self) -> ProgramResult {
    let data = self.accounts.escrow.try_borrow_data()?;
    let escrow = Escrow::load(&data)?;

    // Check if the escrow is valid
    let escrow_key = create_program_address(&[b"escrow", self.accounts.maker.key(), &escrow.seed.to_le_bytes(), &escrow.bump], &crate::ID)?;
    if &escrow_key != self.accounts.escrow.key() {
      return Err(ProgramError::InvalidAccountOwner);
    }
    
    let seed_binding = escrow.seed.to_le_bytes();
    let bump_binding = escrow.bump;
    let escrow_seeds = [
      Seed::from(b"escrow"),
      Seed::from(self.accounts.maker.key().as_ref()),
      Seed::from(&seed_binding),
      Seed::from(&bump_binding),
    ];
    let signer = Signer::from(&escrow_seeds);
    
    let amount = TokenAccount::get_amount(self.accounts.vault);
    
    // Transfer from the Vault to the Taker
    Transfer {
      from: self.accounts.vault,
      to: self.accounts.taker_ata_a,
      authority: self.accounts.escrow,
      amount,
    }.invoke_signed(&[signer.clone()])?;

    // Close the Vault
    CloseAccount {
      account: self.accounts.vault,
      destination: self.accounts.maker,
      authority: self.accounts.escrow,
    }.invoke_signed(&[signer.clone()])?;

    // Transfer from the Taker to the Maker
    Transfer {
      from: self.accounts.taker_ata_b,
      to: self.accounts.maker_ata_b,
      authority: self.accounts.taker,
      amount: escrow.receive,
    }.invoke()?;

    // Close the Escrow
    drop(data);
    ProgramAccount::close(self.accounts.escrow, self.accounts.taker)?;

    Ok(())
  }
}
```
