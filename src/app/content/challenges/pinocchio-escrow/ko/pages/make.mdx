# 생성 (Make)

`make` 명령어는 세 가지 작업을 수행합니다:
- 에스크로 레코드를 초기화하고 모든 거래 조건을 저장합니다.
- 보관소(`escrow` 소유의 `mint_a`에 대한 ATA)를 생성합니다.
- SPL-Token 프로그램에 대한 CPI를 사용하여 메이커의 토큰 A를 해당 보관소로 이동합니다.

<ArticleSection name="필수 계정" id="required-accounts" level="h2" />

이 컨텍스트에 필요한 계정은 다음과 같습니다:

- maker: 에스크로의 생성자. 서명자(signer)이자 가변(mutable)이어야 함
- escrow: 초기화하려는 에스크로 계정. 가변이어야 함
- mint_a: 에스크로에 예치하는 토큰
- mint_b: 받기를 원하는 토큰
- maker_ata_a: 메이커가 소유한 연결된 토큰 계정. 가변이어야 함
- vault: 에스크로가 소유한 연결된 토큰 계정. 가변이어야 함
- system_program: 시스템 프로그램. 실행 가능(executable)이어야 함
- token_program: 토큰 프로그램. 실행 가능이어야 함

**참고**: [Pinocchio 소개](/ko/courses/introduction-to-pinocchio/pinocchio-accounts)에서 소개한 도우미를 사용할 것입니다.

코드에서는 다음과 같습니다:

```rust
pub struct MakeAccounts<'a> {
  pub maker: &'a AccountInfo,
  pub escrow: &'a AccountInfo,
  pub mint_a: &'a AccountInfo,
  pub mint_b: &'a AccountInfo,
  pub maker_ata_a: &'a AccountInfo,
  pub vault: &'a AccountInfo,
  pub system_program: &'a AccountInfo,
  pub token_program: &'a AccountInfo,
}

impl<'a> TryFrom<&'a [AccountInfo]> for MakeAccounts<'a> {
  type Error = ProgramError;

  fn try_from(accounts: &'a [AccountInfo]) -> Result<Self, Self::Error> {
    let [maker, escrow, mint_a, mint_b, maker_ata_a, vault, system_program, token_program, _] = accounts else {
      return Err(ProgramError::NotEnoughAccountKeys);
    };

    // Basic Accounts Checks
    SignerAccount::check(maker)?;
    MintInterface::check(mint_a)?;
    MintInterface::check(mint_b)?;
    AssociatedTokenAccount::check(maker_ata_a, maker, mint_a, token_program)?;

    // Return the accounts
    Ok(Self {
      maker,
      escrow,
      mint_a,
      mint_b,
      maker_ata_a,
      vault,
      system_program,
      token_program,
    })
  }
}
```

<ArticleSection name="명령어 데이터" id="instruction-data" level="h2" />

전달해야 할 명령어 데이터는 다음과 같습니다:
- seed: 시드 파생에 사용되는 임의의 숫자. u64여야 함
- receive: 메이커가 받기를 원하는 금액. u64여야 함
- amount: 메이커가 예치하려는 금액. u64여야 함

`amount`가 0이 아닌지 확인합니다. 에스크로의 경우 0은 의미가 없기 때문입니다.

코드에서는 다음과 같습니다:

```rust
pub struct MakeInstructionData {
  pub seed: u64,
  pub receive: u64,
  pub amount: u64,
}

impl<'a> TryFrom<&'a [u8]> for MakeInstructionData {
  type Error = ProgramError;

  fn try_from(data: &'a [u8]) -> Result<Self, Self::Error> {
    if data.len() != size_of::<u64>() * 3 {
      return Err(ProgramError::InvalidInstructionData);
    }

    let seed = u64::from_le_bytes(data[0..8].try_into().unwrap());
    let receive = u64::from_le_bytes(data[8..16].try_into().unwrap());
    let amount = u64::from_le_bytes(data[16..24].try_into().unwrap());

    // Instruction Checks
    if amount == 0 {
      return Err(ProgramError::InvalidInstructionData);
    }

    Ok(Self {
      seed,
      receive,
      amount,
    })
  }
}
```

<ArticleSection name="명령어 로직" id="instruction-logic" level="h2" />

`instruction_data`와 `accounts`를 모두 역직렬화한 후 `TryFrom` 구현에서 필수 계정을 초기화하는 것으로 시작합니다.

이 단계에서는 [Pinocchio 소개](/ko/courses/introduction-to-pinocchio/pinocchio-accounts)에 소개된 도우미 함수의 `ProgramAccount::init::<Escrow>` 특성을 사용하여 `Escrow` 계정을 만듭니다. 마찬가지로 Vault 계정도 새로 만들어야 하므로 초기화합니다:

```rust
pub struct Make<'a> {
  pub accounts: MakeAccounts<'a>,
  pub instruction_data: MakeInstructionData,
  pub bump: u8,
}

impl<'a> TryFrom<(&'a [u8], &'a [AccountInfo])> for Make<'a> {
  type Error = ProgramError;
  
  fn try_from((data, accounts): (&'a [u8], &'a [AccountInfo])) -> Result<Self, Self::Error> {
    let accounts = MakeAccounts::try_from(accounts)?;
    let instruction_data = MakeInstructionData::try_from(data)?;

    // Initialize the Accounts needed
    let (_, bump) = find_program_address(&[b"escrow", accounts.maker.key(), &instruction_data.seed.to_le_bytes()], &crate::ID);

    let seed_binding = instruction_data.seed.to_le_bytes();
    let bump_binding = [bump];
    let escrow_seeds = [
      Seed::from(b"escrow"),
      Seed::from(accounts.maker.key().as_ref()),
      Seed::from(&seed_binding),
      Seed::from(&bump_binding),
    ];
            
    ProgramAccount::init::<Escrow>(
      accounts.maker,
      accounts.escrow,
      &escrow_seeds,
      Escrow::LEN
    )?;

    // Initialize the vault
    AssociatedTokenAccount::init(
      accounts.vault,
      accounts.mint_a,
      accounts.maker,
      accounts.escrow,
      accounts.system_program,
      accounts.token_program,
    )?;

    Ok(Self {
      accounts,
      instruction_data,
      bump,
    })
  }
}
```

이제 에스크로 계정을 채운 다음 토큰을 보관소로 전송하는 로직 자체에 집중할 수 있습니다.

```rust
impl<'a> Make<'a> {
  pub const DISCRIMINATOR: &'a u8 = &0;
  
  pub fn process(&mut self) -> ProgramResult {
    // Populate the escrow account
    let mut data = self.accounts.escrow.try_borrow_mut_data()?;
    let escrow = Escrow::load_mut(data.as_mut())?;
    
    escrow.set_inner(
      self.instruction_data.seed,
      *self.accounts.maker.key(),
      *self.accounts.mint_a.key(),
      *self.accounts.mint_b.key(),
      self.instruction_data.receive,
      [self.bump],
    );

    // Transfer tokens to vault
    Transfer {
      from: self.accounts.maker_ata_a,
      to: self.accounts.vault,
      authority: self.accounts.maker,
      amount: self.instruction_data.amount
    }.invoke()?;

    Ok(())
  }
}
```
