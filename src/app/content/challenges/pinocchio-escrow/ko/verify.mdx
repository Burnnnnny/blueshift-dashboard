<ChallengeTitle>피노키오 에스크로 (Pinocchio Escrow)</ChallengeTitle>

이제 배운 내용을 테스트해 볼 시간입니다. 수업에서 배운 내용을 사용하여 다음 요구 사항을 충족하는 Pinocchio 프레임워크를 사용하는 에스크로 프로그램을 만드세요.

<RequirementList>
  <Requirement title="도전 과제 1: 에스크로 제안 생성 (Making an escrow offer)">
    프로그램은 메이커가 에스크로 제안을 할 수 있도록 해야 합니다. 명령어 판별자 값 `0`을 사용하여 이를 수행하는 명령어를 정의하세요.
  </Requirement>

  <Requirement title="도전 과제 2: 에스크로 제안 수락 (Taking an escrow offer)">
    프로그램은 테이커가 에스크로 제안을 수락할 수 있도록 해야 합니다. 명령어 판별자 값 `1`을 사용하여 이를 수행하는 명령어를 정의하세요.
  </Requirement>

  <Requirement title="도전 과제 3: 에스크로 제안 취소 (Canceling an escrow offer)">
    프로그램은 메이커가 에스크로 제안을 취소하고 에스크로된 자금을 환불할 수 있도록 해야 합니다. 명령어가 명령어 판별자 값 `2`로 정의되어 있는지 확인하세요.
  </Requirement>
</RequirementList>
